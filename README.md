# Objects Slideshow

Grids of object images scrolling across the screen, with camera-like effects.
A free app for Windows 10 / 11 (64-bit).

- **Website:** https://namtpham.github.io/objects-slideshow-app/ (what's new, feedback)
- **Download:** [Releases](https://github.com/namtpham/objects-slideshow-app/releases/latest):
  unzip one of the two zips and start `Objects Slideshow.exe`.

This repository holds the app's website and its releases only.
